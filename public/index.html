Pas de lien YouTube ? Analyser un fichier vidéo

Le fichier est analysé sur ton PC. Avec un fichier de sous-titres (.srt / .vtt), les titres sont meilleurs et tu peux incruster les sous-titres.

Créer le Short

ffmpeg n'est pas installé sur cet ordinateur. Dans PowerShell, tapez winget install Gyan.FFmpeg, puis fermez et rouvrez le terminal et relancez le site.

N'utilisez que des vidéos dont vous avez les droits : les vôtres, ou celles d'un partenaire qui vous y autorise.
